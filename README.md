# TokenLite ⚡
> Paste smarter. Use less tokens.

TokenLite is a Chrome extension that converts screenshots, PDFs, and DOCX 
files into markdown before they reach the AI — saving up to 93% of input tokens.

## Works on
Claude · ChatGPT · Gemini · Perplexity

## Install
1. Download from [Releases](https://github.com/divydivyanshu/tokenlite/releases/tag/v1.0.0)
2. Unzip the file
3. Open Chrome → chrome://extensions
4. Enable Developer mode
5. Click "Load unpacked" → select tokenlite-extension folder
6. Pin to toolbar

Full install guide: https://divyanshu.works/tokenlite

## Features
- Screenshot Ctrl+V → auto-converts to markdown
- PDF/DOCX → local conversion, unlimited and free
- 5 free screenshot conversions (no login required)
- Works on Claude, ChatGPT, Gemini, Perplexity

## Privacy
No account. No tracking. No API key needed.
